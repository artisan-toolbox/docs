# Versioning

This documentation site follows [Semantic Versioning](https://semver.org/) independently from the packages it documents. The canonical site version is the `version` field in `package.json`.

## Release Types

- Patch releases correct or clarify existing documentation.
- Minor releases add documentation or site capabilities without removing established URLs.
- Major releases may reorganize public URLs or remove documentation for unsupported package generations.

Release tags use the `vMAJOR.MINOR.PATCH` format.

Package releases keep their own versions. A documentation release does not imply a release of Core, Dump to Console, Maintainer, or any other Artisan Toolbox package.
