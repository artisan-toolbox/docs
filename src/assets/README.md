# Brand assets

This directory contains visual assets used by the Artisan Toolbox documentation.

The `artisan-toolbox-logo-concept.png` file is an initial raster logo concept. It should be redrawn as a production SVG and reviewed for trademark clearance before public release.

The `maintainer/` directory contains copies of the SVGs from the Maintainer repository's `logo/` directory. Keep these copies in sync when the logo changes. The overview uses the wordmark for the active theme, and the other Maintainer pages use the standalone icon.

The `mosaicast/` directory contains copies of the SVGs from the Mosaicast repository's `logo/` directory. Keep these copies in sync when the logo changes. The overview uses the wordmark for the active theme, and the other Mosaicast pages use the standalone icon.

The `front-awesome/` directory contains copies of the SVGs from the Front Awesome repository's `logo/` directory. Keep these copies in sync when the logo changes. The overview uses the wordmark for the active theme, and other Front Awesome pages use the standalone icon.

The `qztray/` directory contains copies of the SVGs from the QZ Tray Connector repository's `logo/` directory. Keep these copies in sync when the logo changes. The overview uses the wordmark for the active theme, and the other QZ Tray Connector pages use the standalone icon.

The `core/` directory contains copies of the Core repository's `logo/` SVGs. The overview uses the wordmark for the active theme, and the other Core pages use the standalone icon.

The `dump-to-console/` directory contains copies of the Dump to Console repository's `logo/` SVGs. The overview uses the wordmark for the active theme, and the other Dump to Console pages use the standalone icon.
