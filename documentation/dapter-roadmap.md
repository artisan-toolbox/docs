# Dapter roadmap

Read the architecture, delivery phases, and current progress in the [Dapter roadmap](https://atb.dev.br/docs/dapter/roadmap).
The local preview implements Collection and native SQLite, MySQL, and PostgreSQL offset reads. Explicit backend v2 adds declared field search, typed filters, and single-field ordering, plus source and driver registries. The Vue adapter retains protocol v1 by default. Explicit protocol 2 adds declared Vue controls, independent row and definition decoding, URL history namespaces, and scoped scroll behavior. Run the [functional listing examples](https://atb.dev.br/docs/dapter/listing) and [backend field guides](https://atb.dev.br/docs/dapter/field-search) for delivered behavior. Run the [Vue control guide](https://atb.dev.br/docs/dapter/vue-controls), [definition guide](https://atb.dev.br/docs/dapter/vue-definitions), and [URL navigation guide](https://atb.dev.br/docs/dapter/vue-navigation) for those public APIs. The preview also implements native authorized actions on either read version and composed protocol 2 global search, enum-aware filters, bounded multi-order, opaque presets, and declared joined or grouped queries. Follow the [native actions guide](https://atb.dev.br/docs/dapter/actions) and [global search guide](https://atb.dev.br/docs/dapter/global-search) for executable examples. Source-owned protocol 2 pagination now supports simple and cursor traversal with nullable navigation, optional exact counts, scoped authenticated tokens, and explicit recovery. Follow the [simple guide](https://atb.dev.br/docs/dapter/simple-paging), [cursor guide](https://atb.dev.br/docs/dapter/cursor-paging), and [recovery guide](https://atb.dev.br/docs/dapter/cursor-recovery). Optional Resources work with both read versions. Registered scoped live replacements and independent polling use explicit protocol 2 owners. Follow the [Resource guide](https://atb.dev.br/docs/dapter/resources), [live authorization guide](https://atb.dev.br/docs/dapter/live-authorization), and [polling guide](https://atb.dev.br/docs/dapter/polling). Guarded infinite windows use explicit protocol 2 owners. Follow the [vertical guide](https://atb.dev.br/docs/dapter/infinite-loading), [horizontal guide](https://atb.dev.br/docs/dapter/horizontal-infinite-loading), and [recovery guide](https://atb.dev.br/docs/dapter/infinite-recovery). No stable release is available.

The [canonical roadmap source](../resources/js/pages/docs/dapter/Roadmap.vue) owns the delivery phases, task statuses, acceptance gates, and implementation baseline.
Detailed proposals live in the [proposed design guides](https://atb.dev.br/docs/dapter/design), with one page for declarations, drivers, operations, pagination and state, actions, and live updates.
The [shared fixture reference](https://atb.dev.br/docs/dapter/design/fixtures) separates current runtime checks, executable design references, and specification-only native expectations. Phase 0 contract review, Phase 1 backend acceptance gates, and all eight Phase 2 Vue tasks are complete. All five Phase 2a native-action tasks and all six Phase 3 composed-operation tasks passed their final acceptance gates and are complete. All six Phase 4 pagination tasks passed their acceptance gates and are complete. All seven Phase 3a Resource, live-update, and polling tasks passed their acceptance gates and are complete. All five Phase 5 guarded infinite-loading cards passed their acceptance gates and are complete. Later implementation gates remain explicit in the canonical roadmap.
Their [Vue sources](../resources/js/pages/docs/dapter/design) own the authored examples and stable section anchors. These guides explicitly distinguish proposed APIs from delivered preview behavior.
Independent adapters keep independent state even when they use the same source. Sharing requires an explicit client handle.
The registered documentation route is `docs.show`. The roadmap slug is `dapter/roadmap`, and the design group is `dapter/design`.

Phases form a collapsible list. Opening a phase reveals task cards with their acceptance details already visible.
Compact status badges sit beside phase and task titles. Direct task links open the owning phase, and progress counts only completed tasks.
