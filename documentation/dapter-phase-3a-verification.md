## Limits and provenance

This is an unpublished local preview. Remote CI and Windows were not run locally. Independent reviews used the configured GPT-6 model family and do not provide cross-family corroboration. Source/context factories must reconstruct current application membership, supply explicit reader dependencies and complete scope/projection labels, and advance the generation when trusted semantics change. Public projection is a deliberate globally-safe application assertion. Existing channel patterns must be canonical when enabling live definitions.

Events replace existing rows only. They do not insert, delete, reorder, reconcile list membership, refresh native action metadata or establish snapshot consistency. Without revisions, arrival order does not establish database freshness. Deduplication is finite. Buffered and reentrant replay share the 128-event and 1 MiB bounds. Cache admission expires after 24 hours and reconnect may require an explicit read. Known authentication, tenant and permission changes require resetContext or ordinary owner disposal. Application Echo owns channel disposal; Dapter removes its exact callbacks and owner references. Multi-connection commit coordination and replica consistency remain application responsibilities.

Model the Domain kept recipient and frontend work states explicit. Boundary Discipline placed authorization, ID, Resource and event parsing before protected work or state acceptance. Type System Discipline retained typed record modes and existing Vue inference. Sequence Work into Verifiable Units separated projection, context, update, listener and polling checks. Prove It Works required actual SQL engines, encrypted Worker execution, packed peers and backend-to-Echo browser delivery before completion.
