## Limits and provenance

This is a local unpublished preview, not a package release. Remote CI and its Windows matrix were not run locally. Independent reviews used the configured model family and do not provide cross-family corroboration. The inherited NodeNext declaration limitation remains documented; it uses the conservative generated minimum SDK baseline while Bundler uses exact installed SDK declarations.

Trusted source and handler code can perform its own I/O and must supply complete application authorization scope revisions. Native comparison follows database collation. Collections are materialized and String cursor comparison is lexical. Schema/null/identity eligibility probes may run without exact counts. Counts and rows can observe separate moments. A mutable ordering value can cause repeat or omission during live traversal. No snapshot, high-water limit or browser-spanning transaction was added. Native Inertia URL reconciliation limits from the earlier Vue phase remain documented.
