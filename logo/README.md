# Artisan Toolbox brand assets

This directory contains the official Artisan Toolbox logo assets and the earlier design explorations.

## Production assets

- `artisan-toolbox-logo-dark.png`: transparent full logo with a white `ARTISAN` wordmark for dark contexts.
- `artisan-toolbox-logo-light.png`: transparent full logo with the original charcoal `ARTISAN` wordmark for light contexts.
- `artisan-toolbox-icon.png`: transparent standalone icon used as the website favicon.

The approved original raster artwork is the visual source of truth. The production PNG files preserve its icon, typography, perspective, glow, antialiasing, and alpha channel. The dark variant changes only the charcoal `ARTISAN` wordmark to white for contrast; the light variant preserves its original color.

The website uses the approved PNG files directly. This intentionally avoids an approximate vector redraw changing the approved artwork.

## Earlier concepts

- `artisan-toolbox-concept-dark.png`: original dark presentation with the full lockup and standalone emblem.
- `artisan-toolbox-lockup-preview.png`: simplified horizontal lockup on a simulated transparency grid.
- `artisan-toolbox-lockup-transparent.png`: simplified horizontal lockup with a genuine transparent background.

The earlier files are retained as design history and should not be used as production assets.
