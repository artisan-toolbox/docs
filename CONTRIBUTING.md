# Contributing

Thank you for helping improve the Artisan Toolbox documentation.

## Before You Start

- Keep community-facing content in English.
- Confirm that the documented behavior matches the relevant package version.
- Prefer focused changes that update existing pages instead of duplicating information.
- Use relative links for pages within this documentation site.

## Local Validation

Install dependencies and run the complete validation suite:

```bash
npm install
npm test
```

Use `npm run dev` to preview content while writing.

## Pull Requests

Explain what changed, which packages are affected, and whether any published URL or documented compatibility statement changed. Keep implementation, examples, and documentation synchronized across repositories when a package behavior change requires it.
